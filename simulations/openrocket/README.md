# OpenRocket workflow
Download from [the official site](https://openrocket.info/) and follow its documentation. Record the installed version rather than assuming a fixed latest release.

1. Choose an actual rocket only after budget and field requirements are clear.
2. Enter component dimensions, masses, recovery configuration, and launch-guide details.
3. Separate estimated pre-build properties from measured finished properties.
4. Select the exact manufacturer-approved motor and delay.
5. Set site elevation, atmospheric inputs, wind, guide length, and orientation.
6. Check loaded CG, estimated CP, guide departure speed, recovery timing, and warnings.
7. Save the .ork file plus input provenance and a named simulation run.
8. Export predicted apogee, velocity, acceleration, and relevant time histories.
9. Preserve the preflight version. Revise in a new version after comparing observations.

Record whether plotted acceleration includes gravity and which reference frame/channel is used. Do not compare an accelerometer's proper acceleration blindly with a simulator’s trajectory acceleration.

No .ork file exists yet. Simulation alone does not authorize launch.

# Glossary

| Term | Meaning |
|---|---|
| Apogee | Highest point of a trajectory |
| CG | Centre of gravity; closely coincides with centre of mass in our small vehicle |
| CP | Effective location of aerodynamic normal force for specified conditions |
| Static margin | Axial CG–CP separation divided by reference diameter |
| Impulse | Force accumulated over time |
| Specific impulse | Thrust divided by propellant weight-flow rate, commonly seconds |
| Drag coefficient | Dimensionless factor tied to an explicit reference area |
| Dynamic pressure | Half density times relative air speed squared |
| Resolution | Smallest distinguishable instrument increment |
| Repeatability | Agreement of measurements under repeated conditions |
| Systematic error | Bias not removed merely by repeating a measurement |
| Uncertainty | Quantified limitation on what a result establishes |
| Verification | Checking that a model/calculation was implemented correctly |
| Validation | Testing how adequately it represents observations for its purpose |
| Delta-v | Change in velocity; ideal capability differs from realized trajectory gain |
